## 배경 개념

도구 연동은 외부 프로그램의 기능을 안전한 인터페이스로 제공하는 방법입니다.

## 전체 실습 흐름

1. 입력 데이터 정의
2. 프로그램 실행
3. 결과 검사
4. 오류 상황 확인

## 첫 번째 Python 도구

```python
# 두 정수를 합산하는 간단한 도구

def add(a: int, b: int) -> int:
    return a + b

print(add(2, 3))
```

예상 출력:

```text
5
```

## 실패 상황 검증

```python
# 허용되지 않은 입력 자료형을 사전 검증

def safe_add(a, b):
    if not isinstance(a, int) or not isinstance(b, int):
        raise TypeError("정수만 허용")
    return a + b
```

## 핵심 정리

도구 호출 결과는 반드시 확인하며, 외부 작업에는 적절한 권한 제한과 오류 처리가 필요합니다.
