## 배경 개념

**개발환경**은 소스 코드를 작성하고 실행·검증하기 위한 도구 모음입니다. 프로젝트별로 Python 가상환경을 분리하여 의존성 충돌을 방지합니다.

## 전체 실습 흐름

1. Ubuntu와 Python 설치 상태 확인
2. 작업 디렉터리 및 가상환경 생성
3. 간단한 Python 코드 실행
4. 테스트 결과 확인

## 개발환경 확인

```bash
# Ubuntu 운영체제 정보 확인
lsb_release -a

# Python과 Git 설치 버전 확인
python3 --version
git --version
```

## 가상환경 구성

```bash
# 실습 폴더 생성 및 이동
mkdir -p ~/edu-lab
cd ~/edu-lab

# Python 가상환경 생성·활성화
python3 -m venv .venv
source .venv/bin/activate
```

## 코드 작성과 실행

파일명: `hello.py`

```python
# 정상 실행 여부를 확인하는 가장 작은 예제

def hello(name: str) -> str:
    return f"Hello, {name}!"

if __name__ == "__main__":
    print(hello("Agent"))
```

예상 출력:

```text
Hello, Agent!
```

## 테스트 및 검증

파일명: `test_hello.py`

```python
from hello import hello


def test_hello():
    assert hello("Agent") == "Hello, Agent!"
```

```bash
# 테스트 도구 설치
python -m pip install pytest

# 단위 테스트 실행
python -m pytest -q
```

**완료 기준:** 정상 실행, 테스트 통과, 생성한 파일과 명령의 의미 설명.
